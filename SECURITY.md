# Security

Pocket XR runs with powerful permissions:
- an accessibility service that taps on the glasses' display;
- shell access through Shizuku, to create windows and start apps;
- access to the glasses' camera and their USB network.

Please report anything that could let another app or person misuse those permissions **privately**, not in a public
issue.

## How to report

- **On GitHub:** use "Report a vulnerability" on the Security tab (private vulnerability reporting).
- **By email:** connect@mikehaye.com, with "Pocket XR security" in the subject.

Include:
- what the problem is;
- how to reproduce it;
- which version you tested.

You'll get a reply within a week. Once a fix is released, you'll be credited if you'd like to be.

## Supported versions

Only the latest release gets security fixes.
